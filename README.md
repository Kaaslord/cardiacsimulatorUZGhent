# cardiacsimulatorUZGhent
Kerremans Oliver cardiac simulator

## Installation on Windows
1. Install [Git](https://git-scm.com/download/win) if it is not already installed.
2. Clone the repository using `git clone https://github.com/your-org/cardiacsimulatorUZGhent.git`.
3. Open the `index.html` file in your preferred browser (Chrome, Edge, or Firefox). No additional software is required.
4. Optionally, to serve the project through a local web server, install [Node.js](https://nodejs.org/) and run `npm install -g http-server` followed by `http-server` in the project folder. Then browse to the provided local address.
